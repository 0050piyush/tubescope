How it works

No servers, no sign-ups. TubeScope runs 100% in your browser.

Get a free YouTube Data API v3 key from Google Cloud Console (10,000 free units/day — a video analysis costs ~1 unit). Guided setup in Settings.

Paste any video or channel URL. TubeScope fetches public stats through the official API — nothing scraped, nothing against ToS.

Get vidIQ-style insights. The open TubeScope Estimates Engine scores SEO, estimates monetization likelihood and ad revenue from niche CPM models, all computed locally.
