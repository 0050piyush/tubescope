Get a free key in 2 minutes

Go to Google Cloud Console → create a project (any name).
Open Cloud Console

Enable the API: APIs & Services → Library → search "YouTube Data API v3" → Enable.

Create the key: APIs & Services → Credentials → Create Credentials → API key. Copy it, paste it above, save. Done.
